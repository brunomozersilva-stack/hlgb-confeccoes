# Histórico — segregação operacional/financeira

O histórico legado mostrado na interface incluía valores unitários e estimativas da facção mesmo para operador autorizado apenas na produção. Novo filtro de apresentação conserva dados operacionais, esconde campos monetários quando falta autorização simultânea de pagamentos de facções e financeiro, exclui eventos de pagamento, mantém informações para perfis autorizados. Não modifica registros, pagamentos, nem a API legada timeline. Se núcleo seguro ausente, histórico não é renderizado; novo login e logout limpam seleção e conteúdo. 28 checks do núcleo (22 anteriores + 6 novos) executados. Ainda falta validar permissão de ponta a ponta e eventuais mudanças de acesso durante sessão, servidor e browser.
