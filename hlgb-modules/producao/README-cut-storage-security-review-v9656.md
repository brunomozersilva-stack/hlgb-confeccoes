# Documentos Corte — revisão de metadados do banco HLGB

Inspeção somente leitura das políticas e esquema: hlgb_records tem module/entity_id/data/revision/updated_at/updated_by/deleted_at e RLS por funções de autorização de módulo; leitura de módulos associados pode ser mais ampla que edição. Nenhum bucket cadastrado retornado, nenhuma política storage.objects retornada. Não criar storage público, não colocar binários em registros financeiros nem assumir autorização via client. Proposta para homologação isolada: área própria de arquivo, bucket privado, metadados vinculados a pedido/modelo/versão, chave única de operação, autorização servidor por vínculo e escopos de Corte, confirmação de bytes/tamanho/hash, controle de revisão transacional, leitura após confirmação, descarte de objetos órfãos e acesso temporário autorizado. Separar responsável informado de usuário autenticado. Testar acesso cruzado, revogação, retry, exclusão, concorrência e retenção. O contrato v96.46 permanece não conectado. Nenhum DDL, bucket, dado, policy ou arquivo real alterado; implementação exige ambiente isolado e revisão de segurança.
