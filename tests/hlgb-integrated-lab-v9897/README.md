# Entrega única HLGB v98.97

Esta PR reúne integralmente os arquivos das PRs #545 (4) e #546 (8), sem interseção, sobre main 37b666c94d6c6d24caac131ec5e394b55ad99dc1. Além disso, abre uma única sessão de homologação local com três fluxos transacionais integrados (facções, cliente e checklist) no mesmo PostgreSQL descartável, usando os contratos SQL anteriores, sem tocar na base comercial. A tela permite efetivamente salvar/editar remuneração normal, inserir/editar avulso, registrar baixa semanal única, receber valor e calcular crédito independente, salvar checklist por cor e reabrir numa segunda sessão. O teste usa dados fictícios. Não há integração com login comercial, WAL, arquivos privados reais, nem deploy; a interface anterior de homologação permanece. O gateway é **somente localhost**, exige ambiente descartável explícito, não aceita SQL do navegador, não usa Supabase.

## Executar localmente

Da raiz do repositório com PostgreSQL e Node 22, iniciar um PostgreSQL **novo e descartável** em localhost:5432, banco hlgb_fixture, usuário postgres, senha fixture_only, sem dados. Por exemplo, em ambiente de desenvolvimento com Docker e porta livre: `docker run --rm --name hlgb-integrated-fixture -p 127.0.0.1:5432:5432 -e POSTGRES_DB=hlgb_fixture -e POSTGRES_PASSWORD=fixture_only postgres:16`. Aguardar pg_isready. Em outro terminal, exportar `HLGB_LAB_ONLY=1 PGHOST=127.0.0.1 PGPORT=5432 PGUSER=postgres PGPASSWORD=fixture_only PGDATABASE=hlgb_fixture`, executar `bash tests/hlgb-integrated-lab-v9897/setup.sh` e `node tests/hlgb-integrated-lab-v9897/server.cjs`. Abrir http://127.0.0.1:4187/. Para reiniciar os dados fictícios, parar o contêiner descartável e criar outro. Não apontar a configuração para banco existente. CI executa a jornada integrada uma vez; não substitui workflows anteriores.
